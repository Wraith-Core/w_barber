# w_barber · الحلاق

## الإصدار 1.0.0 — 2026-11-21

سكربت مستقل لمحلات الحلاقة (الشعر، اللحية، الحواجب، المكياج، دهان الشعر، كراسي الحلاقة، ونمو الشعر الاختياري) يعمل على `w_core` و`VORP` و`RSG` و`QBR` بشكل مستقل تمامًا، ويتكامل تلقائيًا مع `w_creators` و`w_clothing` عند وجودهما.

### الميزات
- قصّات الشعر واللحية (شاملة لحى `019-024`) والحواجب والمكياج مع ألوانها.
- الجلوس على كرسي الحلاقة (`PROP_PLAYER_BARBER_SEAT`) وكاميرا تفاعلية.
- تسعير مستقل لكل خدمة وسقف أقصى للزيارة (`visitCap`) وساعات عمل وصلاحيات وظائف/ACE.
- لوحة إدارة `/barberadmin` لإضافة وتعديل محلات الحلاقة ووضع أو اختيار كراسي الحلاقة داخل اللعبة.

### التشغيل
```cfg
ensure w_lib
ensure w_barber
```
الصلاحية الإدارية للوحة: `w_barber.admin` (وتقبل أيضًا `w_creators.admin` تلقائيًا).
